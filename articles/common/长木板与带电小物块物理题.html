粗糙水平地面上的长木板与带电小物块：一道物理题的详解与"硬伤"分析

Researcher: 摸头你就受着

No.3 Middle School Science and Technology Innovation Academy (No.3 AS) · 研究员

（本文为Rubbish期刊普通类学术垃圾）

题目原文

粗糙水平地面上静置长木板，木板长度 L=1.0 m，厚度 d=0.05 m。木板与地面间动摩擦因数 μ1=0.20；带电小物块和木板上表面间动摩擦因数 μ2=0.30。物块质量 m=0.4 kg，木板质量 M=0.8 kg。固定点电荷对物块有恒定水平向右吸引力 F=1.2 N（仅物块在木板上时受这个库仑力；一旦滑离木板，库仑力立刻消失）。t=0 给物块水平向左初速度 v0=4.0 m/s，物块与木板发生相对滑动，木板也相对地面滑动。重力加速度 g=10 m/s²。

求：

  1. 物块在木板上滑动时，物块的加速度大小 a1、木板的加速度大小 a2；
  2. 经过多长时间物块从木板右端滑出；
  3. 物块滑出木板时的速度；
  4. 物块滑出后做平抛运动，求平抛的水平位移；
  5. 物块滑出之后，木板在地面继续减速到静止，求木板从物块滑出到停下的位移。

一、已知量与符号约定

L = 1.0 m，d = 0.05 m；μ1 = 0.20（木板—地面），μ2 = 0.30（物块—木板）；m = 0.4 kg，M = 0.8 kg；F = 1.2 N（向右，仅在板上时作用于物块）；v0 = 4.0 m/s，方向水平向左；g = 10 m/s²。

约定：先以"向左"为正方向讨论；涉及方向时单独标明。

二、关键摩擦力计算（受力分析基础）

1. 物块与木板之间的滑动摩擦力

f2 = μ2·m·g = 0.30 × 0.4 × 10 = 1.2 N

2. 木板与地面之间的最大静摩擦（数值上等于按动摩擦估出的地面阻力）

f1 = μ1·(M + m)·g = 0.20 × (0.8 + 0.4) × 10 = 2.4 N

注意：物块在板上时，地面对木板的支持力为 (M+m)g，而非 Mg。

三、第（1）问：加速度 a₁、a₂

● 物块的加速度 a₁

物块相对木板向左滑动，因此木板对物块的滑动摩擦力方向向右；库仑吸引力 F 也向右。两力同向，合力向右：

m·a1 = F + f2 = 1.2 + 1.2 = 2.4 N

a1 = 2.4 / 0.4 = 6.0 m/s²

方向：水平向右（与物块初速度方向相反，物块做向左的匀减速）。

▸ 物块加速度大小 a1 = 6.0 m/s²。

● 木板的加速度 a₂ —— 这里必须先判定木板到底动不动

木板受到物块给的反作用力，大小 f2=1.2 N，方向向左；地面要阻碍木板向左运动，需提供向右的静摩擦。地面能给出的最大静摩擦为 f1max ≈ 2.4 N。

向左的驱动力 1.2 N < 地面最大静摩擦 2.4 N ⟹ 木板所受向左的力不足以克服地面摩擦，木板保持静止，并不相对地面滑动。

▸ 按真实物理规律：木板加速度 a2 = 0。

※ 题目文字称"木板也相对地面滑动"，并在第（5）问默认木板滑出前已经运动，这与上述数值判定相互矛盾（详见第五节"题目是否完美"）。若按出题人的本意、强行假设木板在地面上滑动，则常见列式为：

M·a2 = f1 − f2 = 2.4 − 1.2 = 1.2 N（向右为正）

a2 = 1.2 / 0.8 = 1.5 m/s²

即参考值 a2 = 1.5 m/s²。但此假设在方向与初速度上并不自洽，仅供对照，不能视为严格成立的结论。

四、第（2）~（5）问 参考求解

说明：本题数值存在硬伤（见第五节），下面分两套给出。A 套：按题目"木板滑动"的本意强行求解（应试参考算法）；B 套：按真实物理规律得到的判定与结论。

A 套：按题目设定（木板在地面上滑动）强行计算

以向左为正方向：物块初速度 v0 = +4.0 m/s，物块加速度 a1 = −6.0 m/s²（向右）；木板初速度 0，加速度 a2 = −1.5 m/s²（向右，参考值）。

相对初速度：vrel0 = v0 − 0 = 4.0 m/s（物块相对板向左）；相对加速度：arel = a1 − a2 = −6.0 − (−1.5) = −4.5 m/s²。

（2）滑出时间 t

相对位移达到板长 L：

L = vrel0·t + (1/2)·arel·t²

1 = 4.0 t − 0.5 × 4.5 × t² ⟹ 2.25 t² − 4 t + 1 = 0

t = [4 ± √(16 − 9)] / (2×2.25) = [4 ± √7] / 4.5

两个根：t₁ ≈ 0.301 s，t₂ ≈ 1.477 s。取物理上先发生的根：t ≈ 0.301 s。

（3）滑出时物块速度（向左为正）

v1 = v0 + a1·t = 4.0 − 6.0 × 0.301 ≈ 2.19 m/s

▸ 物块滑出时速度大小约 2.19 m/s，方向水平向左。（木板此时速度 v2 = 0 − 1.5×0.301 ≈ −0.451 m/s，即向右约 0.451 m/s。）

（4）平抛水平位移

滑出后库仑力消失，物块只受重力，做平抛运动。下落高度即板厚 d=0.05 m：

d = (1/2)·g·tflight² ⟹ tflight = √(2d/g) = √(2×0.05/10) = 0.10 s

x = v1 · tflight = 2.19 × 0.10 ≈ 0.219 m

▸ 平抛水平位移约 0.219 m（方向向左）。

（5）木板滑出后减速到静止的位移

物块离开后，木板对地面压力变为 Mg，地面摩擦 f1' = μ1·M·g：

f1' = 0.20 × 0.8 × 10 = 1.6 N ⟹ a' = f1'/M = 2.0 m/s²

木板滑出瞬间速度大小 |v2| ≈ 0.451 m/s，匀减速到 0：

s = |v2|² / (2a') = 0.451² / (2×2.0) ≈ 0.051 m

▸ 木板从滑出到停下的位移约 0.051 m。

B 套：按真实物理规律的判定

由第三节，地面最大静摩擦 2.4 N > 物块给板的摩擦力 1.2 N，故：

  • 木板始终静止：a2 = 0，不存在"滑出后木板继续减速滑行"的过程，第（5）问在真实情形下不成立（位移为 0，木板未动）。
  • 物块在板上：a1 = 6.0 m/s² 向右，向左做匀减速。物块向左速度减到 0 之前能滑行的最大距离：xmax = v0²/(2a1) = 4.0²/(2×6.0) ≈ 1.33 m > L = 1.0 m。也就是说物块在向左减速到零之前，相对木板就已经滑出板的左端，而不是题目所说的"右端"。
  • 因此在真实物理下：物块会从左端滑离，滑离时速度仍向左、大小为 v = √(v0² − 2a1L) = √(16 − 12) = 2.0 m/s；但题目第（3）(4)问按"右端水平飞出做平抛"设定，与实际滑出方向、初始位置均不对应，平抛模型不能直接套用。

五、这道题是否完美？—— 结论：不完美，存在多处硬伤

【总体结论】题目情境包装完整、设问链条清晰（加速度 → 时间 → 末速度 → 平抛 → 木板减速），作为一道多过程综合题的"框架"是可取的；但参数与物理过程存在实质性矛盾，不是一道严谨、完美的题。

【主要瑕疵逐条】

  1. 木板是否滑动：数值与文字矛盾（最核心硬伤）。物块给木板的摩擦力 f2=1.2 N，而地面最大静摩擦 f1max=2.4 N，1.2 < 2.4，木板应当静止；题目却写明"木板也相对地面滑动"，并在第（5）问默认木板已有滑行速度。受力数据不足以支撑题设运动过程。
  2. 摩擦力方向不自洽。即便强行假设木板滑动，物块对板的摩擦向左（1.2 N）、地面摩擦向右（2.4 N），合力向右，木板初速度为 0，理应向右加速；可一旦木板向右运动，地面摩擦方向又应改为向左。方向随运动状态反复翻转，列式无法闭环，这正是"驱动力小于最大静摩擦、板不能动"的表现。
  3. 滑出端与初速度方向矛盾。物块 t=0 时初速度向左，按真实运动应从木板左端滑出；题目却要求从"右端"滑出，且未说明物块初始在板上的位置（左端/右端/中点），几何条件缺失。
  4. 库仑力"恒定大小、恒定向右"的理想化问题。固定点电荷的库仑力大小 F=kQq/r²，随物块到点电荷距离变化而改变，方向也未必始终水平；题设"恒定水平向右吸引力"是人为假定，需在题干中明确说明"已等效为恒力"，否则与库仑定律不符。
  5. 平抛条件交代不足。平抛要求飞出瞬间速度沿水平方向。题目未说明物块到达板边缘时竖直速度为零、边缘高度如何取；板厚 d=0.05 m 被当作平抛下落高度，但物块在板上表面运动，飞出时的抛出高度、是否会磕到板的竖直端面，均未交代。
  6. 地面摩擦正压力容易被误算。物块在板上时，地面对木板的支持力是 (M+m)g；物块滑出后才变为 Mg。题目未在设问中点明这一区分，计算第（5）问时容易沿用 (M+m)g 导致木板减速加速度算错。

【若要把题目改严谨，建议】

  • 调大物块对板的摩擦力（或减小 μ1、减小总质量），使 f2 > μ1(M+m)g，保证木板确实能在地面上滑动；
  • 明确物块初始位置（如从木板左端以某速度冲出，或在板中点），并让初速度方向与"从哪端滑出"一致；
  • 说明库仑力已按题意等效为水平恒力；
  • 补充抛出瞬间速度水平、抛出高度等于板厚等平抛条件；
  • 区分物块在板上 / 滑出后两个阶段地面摩擦的正压力。
