三角函数倍角公式的绝妙几何证明

——基于“内部等腰三角形”构造法的严密推导

Researcher: Dr.叶

Rubbish 数理研究所 | 非垃圾类学术档案

前言与构造

本证明采用纯欧几里得几何风格，仅使用等腰三角形底角相等、三角形外角定理以及勾股定理，通过无中生有地构造“内部等腰三角形”，以极其优雅的手法导出 \(\sin 2\alpha = 2\sin\alpha\cos\alpha\) 与 \(\cos 2\alpha = \cos^2\alpha - \sin^2\alpha\)。

在直角三角形 \(ABC\) 中，设 \(\angle C = 90^\circ\)，斜边 \(AB = c\)，直角边 \(BC = a\)、\(AC = b\)，且 \(\angle A = \alpha\)。

第一步：绝妙的“内接等腰”构造

在直角边 \(AC\) 上取一点 \(D\)，使得 \(AD = BD = d\)（因为 \(D\) 在 \(AC\) 上移动，总能找到这个点让 \(AD = BD\)）。

因为 \(AD = BD\)，所以 \(\triangle ABD\) 是等腰三角形，底角相等：\(\angle DAB = \angle ABD = \alpha\)。

看 \(\angle BDC\)，它是 \(\triangle ABD\) 的外角，根据“三角形外角等于不相邻两内角之和”：

\(\angle BDC = \angle DAB + \angle ABD = \alpha + \alpha = 2\alpha\)

第二步：勾股定理求 \(d\)

在直角三角形 \(BCD\)（\(\angle C = 90^\circ\)）中：

  • 斜边是 \(BD = d\)
  • 一条直角边是 \(BC = a\)
  • 另一条直角边是 \(CD = AC - AD = b - d\)

由勾股定理：

$$a^2 + (b-d)^2 = d^2$$

展开：\(a^2 + b^2 - 2bd + d^2 = d^2\)

消去 \(d^2\)，且因原大三角形勾股定理 \(a^2 + b^2 = c^2\)，所以：

$$c^2 = 2bd \implies d = \frac{c^2}{2b}$$

第三步：致命一击（终极证明）

在直角三角形 \(BCD\) 中，\(\angle BDC = 2\alpha\)，因此：

$$\sin 2\alpha = \frac{\text{对边}}{\text{斜边}} = \frac{BC}{BD} = \frac{a}{d}$$

代入刚才求出的 \(d = \frac{c^2}{2b}\) ：

$$\sin 2\alpha = \frac{a}{\frac{c^2}{2b}} = \frac{2ab}{c^2}$$

而在原大直角三角形 \(ABC\) 中：

$$\sin \alpha = \frac{a}{c}, \quad \cos \alpha = \frac{b}{c}$$

所以：

$$2\sin\alpha\cos\alpha = 2 \cdot \frac{a}{c} \cdot \frac{b}{c} = \frac{2ab}{c^2}$$

两边对比，完美得到：

\(\sin 2\alpha = 2\sin\alpha\cos\alpha\)

附带推论：\(\cos 2\alpha\)

同理，斜眼看一下直角三角形 \(BCD\)，能立即读出 \(\cos 2\alpha\)：

$$\cos 2\alpha = \frac{CD}{BD} = \frac{b-d}{d} = \frac{b}{d} - 1 = \frac{2b^2}{c^2} - 1 = \cos^2\alpha - \sin^2\alpha$$

本证法评价

这个证法的逻辑闭环极紧，唯一的小代数运算就是勾股定理展开，没有任何复杂的三角恒等变换。不是去外面补高，而是在内部“藏”了一个等腰三角形，让 \(2\alpha\) 自然地作为外角出现，展现了初中几何的看家本领，堪称绝妙。
